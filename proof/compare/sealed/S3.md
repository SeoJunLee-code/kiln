# Thrust runner: five changes

`game/` holds a working game and the spec it was built from (`game/SPEC.md`). You did not
write it. Make these five changes and break nothing else. Nobody will answer questions.

1. **A shield.** A new thing comes in from the right now and then, drawn unlike a coin.
   Touching it gives the player a shield, shown as a ring around the player. With a
   shield, touching an obstacle does not end the run: the shield is used up, that
   obstacle disappears, and the run goes on. The player holds at most one shield.
2. **A magnet.** Collecting ten coins in one run turns a magnet on for five seconds:
   coins within about a quarter of the screen's height move towards the player by
   themselves. The screen shows the seconds left while it is on. The count towards the
   next magnet starts again from zero.
3. **Three best runs.** The game keeps the three longest distances since it was started,
   not one. The title screen and the `Run over` panel list all three, longest first; the
   distance of the run that just ended is marked in the list when it is on it.
4. **A dash.** Pressing D gives a burst: for half a second the world scrolls at twice its
   current speed and the player passes through coins and obstacles without touching
   either. After a dash, D does nothing for three seconds, and the screen shows whether
   the dash is ready.
5. **A slower start.** For the first three seconds of a run nothing that can end the run
   comes into the screen.

Everything in `game/SPEC.md` that these changes do not replace must still hold.

## What "done" means

- Every file of the game is inside `game/`. It starts as before, with no error and no
  warning.
- The five changes hold for a person who plays with Space, P, D and Enter, and so does the
  rest of `game/SPEC.md`. Check as much as the engine lets you check without a person.

When done, list the files you changed or added and say how the game is started.

## Screen pass checks

| # | Do | See |
|---|---|---|
| 1 | Start the game. | The title lists three best distances, all 0. No error or warning. |
| 2 | Start a run and touch nothing for three seconds. | No obstacle on screen in that time. |
| 3 | Play until a shield pickup comes; touch it. | It looks unlike a coin; a ring shows around the player. |
| 4 | With the ring, touch an obstacle. | The run goes on, the ring is gone, that obstacle is gone. |
| 5 | Without a ring, touch an obstacle. | The run ends as before. |
| 6 | Collect ten coins in one run. | A countdown from about 5 appears; coins nearby drift to the player; after it ends they no longer do. |
| 7 | Press D. | For a moment the world moves about twice as fast and the player passes through an obstacle or coin unharmed and uncollected. |
| 8 | Press D again at once. | Nothing happens; the screen shows the dash is not ready, then ready about three seconds later. |
| 9 | Play four runs of different lengths. | The panel lists the three longest, longest first, and marks the run just ended when it is one of them. |
| 10 | Checks 2, 3, 5, 8, 9 and 10 of S1 (falling and rising, pause, same run twice, colours and speed). | They still hold, except where a change above replaces them. |

A game passes when all ten hold. Check 10 is judged only on what held in the starting game:
a fault the starting game already had is not held against this task.
