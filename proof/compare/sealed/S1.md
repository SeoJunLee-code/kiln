# Thrust runner

A written spec for one small 2D game seen from the side. Build it from this text alone.
Nobody will answer questions.

## The game

1. The player is a small figure near the left edge of the screen. The world scrolls past
   from right to left without stopping; the player's horizontal place on the screen does
   not change.
2. While Space is held the player accelerates upwards. While it is not held, gravity pulls
   the player down. There is a floor and a ceiling; the player rests against either
   without harm.
3. The scrolling starts at a slow speed and gets faster the longer a run lasts, up to a
   limit of at least twice the starting speed.
4. Three kinds of thing come in from the right:
   - **Bars**: obstacles that stand still in the world. Some reach from the floor, some
     from the ceiling, some float in between. Touching one ends the run.
   - **Sweepers**: obstacles that move up and down between floor and ceiling as they
     approach. Touching one ends the run.
   - **Coins**: touching one collects it; it disappears.
5. There is always a way through: no place where the gap left is smaller than twice the
   player's height.
6. The screen shows the distance travelled in metres, counting up, and the number of
   coins collected in this run.
7. What comes in is the same on every run: two runs with the same key presses at the same
   moments are the same run.
8. When a run ends, the scrolling stops and a panel shows `Run over`, the distance, the
   coins, and the best distance of all runs since the game was started. If this run is
   the best, the panel also shows `New best`. Pressing Enter starts a new run from zero.
9. The game opens on a title screen with the game's name, the best distance (0 at first)
   and `Press Enter`. Enter starts a run.
10. Pressing P during a run pauses it: nothing moves, the word `Paused` shows. P again
    continues exactly where it stopped.
11. Every 500 metres the background colour changes, through at least three colours.

## What "done" means

- Every file of the game is inside the folder `game/`.
- The game starts in the engine's ordinary way of running a game, with no error and no
  warning.
- Everything under "The game" holds for a person who plays with Space, P and Enter. Check
  as much of that as the engine lets you check without a person.

When done, list the files and say how the game is started.

## Screen pass checks

A person plays the game as the agent left it, started the way the agent's last message
says. Each check is "do this, see that".

| # | Do | See |
|---|---|---|
| 1 | Start the game. | A title, a best distance of 0, `Press Enter`. No error or warning where it was started. |
| 2 | Press Enter and touch nothing. | The world scrolls right to left; the player falls to the floor and stays there unharmed; a distance counts up; a coin count reads 0. |
| 3 | Hold Space. | The player rises, faster the longer it is held, and stops at the ceiling unharmed. Releasing lets it fall. |
| 4 | Play until each kind has been seen. | Bars from the floor, from the ceiling and floating; at least one obstacle that moves up and down; coins. |
| 5 | Touch a coin. | It disappears; the coin count goes up by one. |
| 6 | Touch a bar. | Scrolling stops. `Run over`, the distance, the coins, a best distance, `New best`. |
| 7 | Press Enter; end the run sooner than before. | A new run from 0 m and 0 coins. The panel's best is the earlier, larger distance and `New best` is absent. |
| 8 | Start two runs and touch nothing in either. | Both end at the same distance against the same obstacle. |
| 9 | Press P mid-run, wait five seconds, press P. | Everything stops with `Paused`, the distance does not change; then it continues from the same place. |
| 10 | Survive past 500 m and past 1000 m. | The background colour changes at each; the scrolling is visibly faster than at the start. |
| 11 | Touch a moving obstacle. | The run ends as in 6. |
| 12 | Play five runs trying to get through. | No wall without a gap the player fits through. |

A game passes when all twelve hold. If a person cannot get past 500 m in ten tries, check
10 fails.
