# Where the example assets come from

Everything in this folder was made for this project and is under the repository's
license (see `LICENSE`). Nothing was downloaded.

| File | Origin |
|---|---|
| `crate.glb`, `orbs.glb`, `ball.glb`, `totem.gltf`, `totem.bin`, `totem.png`, `totem_n.png` | Generated by [`scripts/models.ts`](../scripts/models.ts): geometry from formulas, textures from integer patterns. Run `node scripts/models.ts` to make them again. |
| `gem.obj`, `spire.obj`, `hero.svg`, `grass.svg` | Written by hand. |

The three glTF files are built differently on purpose (embedded textures; files beside
the `.gltf`, a node tree, interleaved vertices, three index widths; shared vertex data),
so that the examples exercise the reader. They were written by this project's own
writer, so they do not show that files from other exporters load.
