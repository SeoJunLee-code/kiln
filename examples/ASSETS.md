# Where the example assets come from

Everything in this folder was made for this project and is under the repository's
license (see `LICENSE`). Nothing was downloaded.

| File | Origin |
|---|---|
| `crate.glb`, `orbs.glb`, `ball.glb`, `totem.gltf`, `totem.bin`, `totem.png`, `totem_n.png` | Generated by [`scripts/models.ts`](../scripts/models.ts): geometry from formulas, textures from integer patterns. Run `node scripts/models.ts` to make them again. |
| `coin.wav`, `door.wav`, `tune.wav` | Generated by [`scripts/sounds.ts`](../scripts/sounds.ts): triangle waves from arithmetic, 8-bit mono at 8 kHz. Run `node scripts/sounds.ts` to make them again. |
| `gem.obj`, `spire.obj`, `hero.svg`, `grass.svg`, `walker.svg`, `bat.svg` | Written by hand. |
| `godot/props.gltf` (+ `props0.bin`, `textures/_albedo.png`), `bend.glb` | Exported by Godot 4.7.2 from geometry that [`scripts/godot/export.gd`](../scripts/godot/export.gd) builds from formulas. No art was imported. Run `godot --headless --path scripts/godot --script export.gd -- OUTDIR` to make them again (it writes both into OUTDIR; `bend.glb` is kept beside the scenes). |

The three glTF files are built differently on purpose (embedded textures; files beside
the `.gltf`, a node tree, interleaved vertices, three index widths; shared vertex data),
so that the examples exercise the reader. They were written by this project's own
writer; the files under `godot/` are what shows that another exporter's files load.
